## 没做

| 能力 | 原因 |
|---|---|
| 主动提醒（定时找人说句话） | 优先级低，且容易变成骚扰 |
| TTS 发语音 | 依赖未定（火山引擎等需要单独账号） |
| 向量检索 | 现在是 `LIKE` 关键词，够用 |
| 群成员之间的上下文隔离 | 群共用一个会话是设计取舍，见 [权限模型](permission-model.md) |
| 图片内文字的关键词过滤 | 需要 OCR，未接 |

## 验证过的地基

| # | 问题 | 结论 |
|---|---|---|
| 1 | Host 插件能否直调 `sessionController` 的 `list/inspect/resolveAgent/follow/prompt` | 通过 6/6（`prompt` 未跑，走同一套包装） |
| 2 | WS 路径与 token 带法 | 路径 `/`；HTTP 与 WS 各一个独立 token |
| 3 | 注入后是否需要重新扫码 | 不需要 |
| 4 | 审批通道 | `ctx.tools.guard` + QQ 里 `/yes` |
| 5 | Electron 宿主的 `node:sqlite` | 可用 |
| 6 | FTS5 | 未用 |
| 7 | GDI+ 中文渲染与 GIF 抽帧 | 通过 |

> 探针见 `dev/session-probe`：一次安装即通过，说明 Remote 方法在进程内调用不会被网关上下文拦住。
