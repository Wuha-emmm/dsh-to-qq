# 剧本：三角洲行动 · 特勤处四个工位生产（重造上一批）

> 环境假设：屏幕 2560×1440、游戏全屏独占、WeGame 已登录（用户名「哞哈」）。
> 坐标系：全屏绝对坐标（像素，左上角为 0,0）。若分辨率变了，全部坐标要等比缩放。
> 首次编写：2026-11-01，依据当晚实操。

## 0. 前置

1. 需要 pwsh 权限：让用户在 QQ 里发 `/yes!`（放开 5 分钟），否则每条命令都会被拦。
2. 每步之后截图确认，不要盲点。截图方式：`System.Windows.Forms` 的 `VirtualScreen` + `CopyFromScreen`。
3. 时间显示是 `时:分:秒`，`29:56:53` = 29 小时 56 分，**不是分钟**。

## 1. 拉起 WeGame 并进入三角洲

| 步骤 | 动作 | 结果判据 |

**坑**：启动按钮右边紧挨着「⋮」三点菜单 (2022, 1090)，点歪会弹「游戏资源包管理 / DLC 管理 / 无痕登录」，按 Esc 关掉重点。

## 4. 四个工位下单（每个工位流程相同）

工位「＋」号坐标：

| 工位 | 坐标 | 要造的东西 |
|---|---|---|
| 技术中心 | (388, 555) | M14射手步枪（工序约 30 小时） |
| 工作台 | (835, 555) | 7.62x51mm M62 ×120（约 8 小时） |
| 制药台 | (388, 988) | 高级头盔维修组合（约 8 小时） |
| 防具台 | (835, 988) | 精英防弹背心（约 8 小时） |

单个工位流程：

1. 点「＋」→ 进入图纸列表（左侧带**名称**，按价格从高到低排序）。
2. 找到目标：列表可能要**向下滚轮**（见 5.1）。目标名必须与上表完全一致，点错就是造错东西。
3. 点中目标后，右侧出现详情（参考价格、仓库数量、材料槽）。
4. 材料全空时点右下「一键补齐」(2244, 1290)。
5. 弹出「一键补齐清单」→ 点底部绿色总价按钮 **(1281, 989)** 付款。
6. 材料变成 `n/n` 后，右下按钮变「生产」，点 (2244, 1270)。
7. 截图确认：按钮变成「中止」、出现「剩余时间」，说明已下单。
8. 按 **Esc 两次** 回特勤处。

### 找图纸的具体位置（容易点偏）

- 技术中心：向下滚 10～11 格轮，M14射手步枪 在 RM277突击步枪 上一行。
- 工作台：向下滚 5 格，7.62x51mm M62 在 7.62x54R BT 下一行。
- 制药台：**不用滚**，第 2 行就是「高级头盔维修组合」；第 1 行是「高级护甲维修组合」，别点错。
- 防具台：向下滚 9 格，精英防弹背心在 Hvk-2防弹衣 下一行。

## 5. 技术细节备忘

### 5.1 滚轮（PowerShell）

`mouse_event` 的 delta 是 uint，负数要换算：

```powershell
$neg = [uint32]4294967176   # -120，即向下滚一格
1..5 | ForEach-Object { [M5]::mouse_event(0x0800,0,0,$neg,[IntPtr]::Zero); Start-Sleep -Milliseconds 150 }
```

先把鼠标移到列表区域（例如 (450, 900)）再滚，否则滚的是别的地方。

### 5.2 点击

```powershell
[void][M]::SetCursorPos($x,$y); Start-Sleep -Milliseconds 300
[M]::mouse_event(0x0002,0,0,0,[IntPtr]::Zero); Start-Sleep -Milliseconds 90
[M]::mouse_event(0x0004,0,0,0,[IntPtr]::Zero)
```

### 5.3 按键

```powershell
$vk = 0x20  # 空格；Tab=0x09；Esc=0x1B
[M]::keybd_event($vk,0,0,[IntPtr]::Zero); Start-Sleep -Milliseconds 80
[M]::keybd_event($vk,0,2,[IntPtr]::Zero);   # 0x2 = KEYEVENTF_KEYUP
```

### 5.4 截图

```powershell
Add-Type -AssemblyName System.Windows.Forms,System.Drawing
$b = [System.Windows.Forms.SystemInformation]::VirtualScreen
$bmp = New-Object System.Drawing.Bitmap $b.Width, $b.Height
$g = [System.Drawing.Graphics]::FromImage($bmp)
$g.CopyFromScreen($b.X,$b.Y,0,0,$bmp.Size)
$bmp.Save("E:\DSH-to-QQ\shot.png", [System.Drawing.Imaging.ImageFormat]::Png)
$g.Dispose(); $bmp.Dispose()
```

### 5.5 C# 类型声明每次 pwsh 都是新进程

`Add-Type` 定义的类型（如 `M14`）不会跨命令保留，每条命令都要重新 `Add-Type`，或写成独立 `.ps1` 一次调用。

## 6. 领取（生产完成后）

1. 进「特勤处」，四个工位显示成品图标和「已完工」。
2. 依次点工位卡片 → 弹「获得奖励」→ 按空格或点「继续」。
3. 四个都领完后，工位变回「空闲中」。

## 7. 安全与风险

- 这个剧本会**花游戏币**买材料（上次四单约 47 万）。执行前必须先确认。
- 点错工位就是造错东西，几乎不能撤，所以每步都要截图确认。
- 游戏更新后 UI 会变，坐标会失效；失效时先截图，按画面重新定位，别硬点。
